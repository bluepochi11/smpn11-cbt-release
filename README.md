# SMPN 11 CBT — Rilis Resmi Aplikasi Siswa

Distribusi resmi berkas APK aplikasi ujian **SMP Negeri 11 Singkawang Timur**.

## Unduh Versi Terbaru (`v2.1.4`)

Buka halaman **[Releases](https://github.com/bluepochi11/smpn11-cbt-release/releases/latest)** untuk mengunduh berkas APK resmi:

- **`SMPN11-CBT-Siswa-v2.1.4.apk`** — Rekomendasi utama (**Universal**, cocok untuk seluruh HP Android siswa).
- **`SMPN11-CBT-Siswa-v2.1.4-arm64-v8a.apk`** — Varian khusus Android 64-bit.
- **`SMPN11-CBT-Siswa-v2.1.4-armeabi-v7a.apk`** — Varian khusus Android 32-bit.
- **`SMPN11-CBT-DEMO-MOD-BedaSignature.apk`** — Berkas demo modifikasi (signature tidak resmi) khusus pengujian anti-modding.
